# 产品需求

## 当前阶段

hk-handbook 当前阶段只建立可运行、可验证的前后端基础工程。
产品用户、具体内容和业务流程待确认，不根据项目名推断业务。

## 本阶段验收

- 一份 uni-app Vue 3 + TypeScript 源码支持 H5 与微信小程序构建。
- Java 21 Spring Boot 后端可启动，SQLite JDBC 可连接。
- 具备可复现构建命令、架构文档、协作规则及 PR 模板。
- 保留已有文件，不开发业务功能，不部署生产。

## 后续待确认

目标用户、核心场景、内容模型、权限与登录、数据来源、API 契约及验收指标。
本阶段不实现这些事项。

## E01 已确认方向（2026-10-17）

以上为初始化阶段记录。根据 [Epic #8](https://github.com/whyboy/hk-handbook/issues/8)，当前产品方向为面向内地赴港游客、人才用户及家庭的免费攻略导航，主题为银行卡、电话卡和交通。
免登录阅读、搜索、分享，本设备收藏及内容纠错；后续内容后台由人工审核发布。
E01 仅交付页面线框／原型、内容规范和真实样稿，不实现生产业务、爬虫、资格测评、支付、订单、社区或跨设备同步。

- [#10 内容规范](https://github.com/whyboy/hk-handbook/issues/10)：交付见 [内容规范](content/STANDARD.md)。
- [#9 页面原型](https://github.com/whyboy/hk-handbook/issues/9)：独立 PR，需创始人评审。
- [#11 真实样稿](https://github.com/whyboy/hk-handbook/issues/11)：依照模板检验阅读顺序，需人工核验和创始人评审。

任务拆分不意味着已通过人工验收；具体状态以各任务 PR 的验证与评审记录为准。
