# E01-T01 页面原型评审入口

任务：[设计首期页面原型与关键用户流程 #9](https://github.com/whyboy/hk-handbook/issues/9)。

本交付采用 Issue 允许的**页面线框**形式，直接在 GitHub 浏览，无需启动应用或部署服务器：

1. 打开 [页面线框与流程](E01-T01.md)，从“评审导航”进入首页、攻略库、搜索、详情和我的。
2. 按“关键路径与评审脚本”推演十条路径，检查空态、失败、分享直达与下架后的返回路径。
3. 在 [人工评审记录](E01-T01-REVIEW.md) 留下真实结果，未完成项不要勾选为通过。

分类与字段对应 [内容规范 PR #15](https://github.com/whyboy/hk-handbook/pull/15)；真实样稿由 [Issue #11](https://github.com/whyboy/hk-handbook/issues/11) 单独交付。本 PR 可独立查看，不要求先合并规范 PR；建议按 #10 → #9 → #11 的顺序评审。

线框不是可交互的生产前端，没有实现真实收藏、搜索、分享或纠错。H5／微信小程序能力差异已写入设计，后续业务开发仍须按 uni-app + Vue 3 + TypeScript 实现并进行真机验证。

原综合 PR #14 的独立 HTML 交互探索保留在其原分支，不在本任务中重复合并。此交付以 Issue 要求的页面、流程及状态为验收范围。
