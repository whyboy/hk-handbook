## 内容加载与维护

生产数据唯一位置：`backend/src/main/resources/content/<id>.json`。启动只读取 classpath 中 `content/*.json`，不扫描 docs、工作目录或用户输入路径；每文件一个对象。当前目录没有正式攻略 JSON，正常列表为空。编辑后需重新构建、启动，生产发布遵循已有人工授权流程；不提供上传、预览或管理接口。

严格执行 [MODEL](../content/MODEL.md) 的固定字段、类型、枚举、长度、ID／引用唯一性、日期、来源 HTTPS URL 与章节结构。读取时去除文本首尾空白，拒绝重复 JSON 键、尾随对象、未知字段、非法日期、文件名不符、悬空引用。结构错误使整个应用启动失败，日志定位文件及字段，不部分加载。

结构合格的内部状态可加载，但列表、搜索和详情共用公开资格判断：仅 published、完整章节、当前 revision 的事实核验／审核／发布记录、有效来源及尚未到期的复核日期才可公开。来源和文章有效期、来源／事实／文章复核期都受限；from 含当天，until 和 reviewDueOn 不含当天。每次请求按 Asia/Hong_Kong 日期重新判断，无需重启即可停止展示到期内容。所有响应 `Cache-Control: no-store`，避免客户端缓存继续显示已失效正文。

启动日志记录未通过公开资格的内容 ID 和阻塞字段，不公开提供诊断接口。真实人工签字和证据内容仍需人工核对，代码不能证明签字真实性；不能填写测试签字来发布真实攻略。测试数据只在 `src/test/resources/content-fixtures`，不会打入生产 JAR。

## REST 契约

### `GET /api/guides`

| 参数 | 默认值／限制 |
| --- | --- |
| category | 可省略；bank / phone / talent / life |
| audience | 可省略；visitor / talent / family |
| q | 可省略；去首尾空白后最多 100 Unicode 码点；标题、摘要、关键词及五个章节正文连续子串匹配，忽略英文大小写 |
| page | 1；1–1000000 整数 |
| size | 20；1–50 整数 |

分类、人群与关键词取交集。先过滤公开资格，再过滤查询，再按相关度排序、计数与分页；标题命中优先，其次关键词／摘要，最后正文，同级发布日期倒序、同日 ID 升序。无关键词按 content/recommendations.txt 编辑推荐 ID 顺序，未推荐的按发布日期倒序、ID 升序。超出最后一页返回空 items 与实际 total。空 category／audience／q 等同省略。重复参数、未知参数（包括 preview）、非法枚举和分页返回 400。

```json
{"items": [], "total": 0, "page": 1, "size": 20}
```

搜索命中摘要或正文时另返回可选 matchExcerpt 纯文本片段，最多 160 码点（不含两端省略号），不搜索内部审核证据或身份。audience 参数保留兼容旧客户端，新搜索页面不再发送该参数。

每个摘要包含 id、revision、title、summary、category、audiences、keywords、editedOn、effectivePeriod（仅 state/from/until）、reviewDueOn、publishedOn、verifiedOn。verifiedOn 从逐条事实核验日期取最早值，不以编辑日期替代。

### `GET /api/guides/{id}`

200：摘要字段加 sections、facts、sources、related。正文保持纯文本，消费端仍须转义。

- sections：五个章节的 state/reason/blocks；block 保留 kind/text/factIds/experienceContext。
- facts：id/claim/conditions/sourceIds，不返回 verification。
- sources：id/organization/title/url/consultedOn/effectivePeriod（仅 state/from/until）。
- related：当前没有已开放的目标解析器，返回空数组，不能创建可执行工具入口。

不返回内部责任人、evidence、rolesNote、linkCheck、原始 review/publication 或内部备注。详情不接受查询参数。

| 情况 | 状态／响应 |
| --- | --- |
| 参数无效 | 400，`{"code":"INVALID_QUERY","message":"查询参数无效"}` |
| 不存在、草稿、待审核、复核到期、公开资格未通过 | 404，`{"code":"CONTENT_UNAVAILABLE","message":"内容不存在或暂不可用"}` |
| withdrawn | 410，`{"code":"CONTENT_WITHDRAWN","id":"…","message":"内容已下架","returnPath":"/pages/guides/index"}`，无标题／正文 |
