# E01-T05：四 Tab、公共页面容器与导航状态

关联 Task #30。四个原生 Tab 固定为首页、工具、攻略、我的；十个页面的注册、标题、Tab 顺序、图标与颜色集中在 frontend/src/pages.json。图标为本项目代码绘制的 PNG，普通与选中状态使用相同图形和不同颜色，两端复用。

## 导航与组件

- frontend/src/navigation/index.ts 集中路由、工具／记录类型参数及导航。顶层页面使用 uni.switchTab，二级页使用 uni.navigateTo；返回首页／相关 Tab 同样使用 switchTab，不依赖历史栈，二级页没有自定义 Tab。
- 原生 Tab 保持页面实例内的展示状态，如攻略分类；刷新不承诺保留，未接持久化存储。
- 清单详情返回清单列表时，优先回已有且类型正确的记录页；否则重新打开指定列表。未知类型、未知／缺失 ID 延用各页面不可用状态。
- PageContainer 统一宽度、边距、安全区，十个页面均接入。
- ContentCard 用于说明、详情、反馈及清单的内容分区；PageState 提供 empty/loading/error/unavailable 展示，已接入攻略与记录页面。
- UnavailableNotice 统一未开放提示，已接入我的和反馈页。展示状态不触发请求或伪报成功。

## 运行与走查

在 frontend 执行 npm ci 和 npm run dev:h5。首页实际路由为 /pages/index/index。微信执行 npm run build:mp-weixin，将 dist/build/mp-weixin 导入开发者工具并配置自己的 AppID。

1. 四 Tab 往返，核对顺序、图标、选中颜色和单一 TabBar。
2. 攻略选分类 → 详情 → 返回攻略，核对分类保留和详情无底部 Tab；换 Tab 后返回再核对。
3. 工具说明／结果、记录、反馈、清单详情分别直达与刷新，再返回相关 Tab 或首页。
4. 未知／缺失 scene、type、id 不崩溃；攻略 demo=loading/empty/error 展示公共状态（列表直接访问带参数地址用于评审，Tab 切换不传 query）。

## 桌面底栏布局调整

H5 在视口宽度达到 760px 时，将四个 Tab 的点击区域限制在居中的 760px 内，底栏背景仍覆盖整个窗口。该样式位于 App.vue 的 H5 条件编译块，避免宽屏下首页和我的离正文过远；窄屏继续四等分全宽，微信小程序保留原生 TabBar。无需新增运行配置。
