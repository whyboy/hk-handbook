# E02-T08：首页搜索与资讯页面框架

关联 Issue #68。首页搜索保留现有攻略查询、分类、分页、异常状态及详情入口，搜索结果改为首页 Tab 内部状态，不再切换到原攻略 Tab。从详情返回时回到搜索结果；详情直达时提供返回首页的兜底。

原 `pages/guides/index` 作为第三个原生 Tab 的稳定路径保留，页面职责和 Tab 文案改为“资讯”。首版提供“最新”“香港学校”“香港政策”三个分类、空状态和前端数据契约。当前没有经核验的资讯数据，不放入示例新闻，不请求资讯 API，也不承诺实时更新。

## 路由与状态

- `/pages/index/index`：首页默认内容与攻略搜索结果共用同一 Tab 页面。
- `/pages/guides/detail?id=<id>`：保留现有攻略详情。
- `/pages/guides/index`：资讯 Tab，不承载攻略搜索。

`openGuides` 保留为既有上下文入口，现在将筛选条件交给首页并切换到首页 Tab。搜索条件只在当前应用实例内保留，不写入持久存储。

## 验证

在 `frontend` 执行 `npm run type-check`、`npm run build:h5` 和 `npm run build:mp-weixin`。H5 需要核对首页搜索前后 Tab 选中状态、结果到详情往返、筛选和异常状态，以及资讯三分类空状态。微信开发者工具、真机和产品人工验收仍需单独执行。
