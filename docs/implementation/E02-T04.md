# E02-T04 攻略浏览搜索与上下文入口

第一版接入 E02-T03 的 `/api/guides` 和 `/api/guides/{id}`，H5 与微信小程序共用 `frontend/src`，不增加业务依赖。原 E01 的攻略静态样例及 `demo` 状态演示不再用于正式页面；示例历史见 E01-T03，内部港铁稿仍在 docs，不进入公开列表。

## 已实现路径

- 首页“搜索攻略”进入列表；“最新攻略”读取最多三篇公开内容，按服务端发布日期排序，不把它称作热门排行。无内容、加载中和失败各有明确状态。
- 列表支持四分类、适用人群、关键词搜索，取交集；清除筛选、20 条分页、加载更多、失败重试。加载更多失败保留已有结果。
- 搜索按钮通过 form submit 读取当前输入；键盘确认读取 confirm 事件值，避免 uni-app 输入绑定值的节流导致提交旧关键词。
- 快速切换筛选或搜索时以请求序号丢弃旧响应；离开页面作废在途请求并清空展示，重新显示时重新请求，避免从页面缓存继续展示已下架正文。筛选条件保留在会话内存中（兼容 Tab 实例被重新创建）；返回列表重新读取第一页，不保留分页位置。
- 详情展示五个章节、事实与条件、来源、适用人群，以及相互独立的编辑／核验／发布／复核日期和有效期；所有正文通过文本插值渲染，无 HTML 注入。
- 404 为不存在或暂不可用，410 单独显示已下架；网络错误、超时、响应格式错误可重试，不显示旧正文。直接进入详情、刷新、缺失／非法 ID 均可返回列表或首页。
- 工具说明按银行卡、人才身份或生活落地进入对应分类；清单页面进入生活落地分类。由于 switchTab 不能传递查询参数，使用一次性内存交接，消费后清除，不持久保存用户输入。
- H5 官方来源打开新标签，弹窗被阻止时尝试复制；微信复制链接供外部浏览器打开。复制成功／失败按 API 回调提示，保留可选中的地址文字。当前关联银行／规则／清单解析器尚未开放，不伪造执行按钮、收藏或分享成功。

## 运行配置

在一个终端按 README 启动后端；另一个终端在 frontend 执行 `npm run dev:h5`。Vite 将 `/api` 代理至 `http://127.0.0.1:8080`。若后端在其他本机端口，可执行：

```bash
API_PROXY_TARGET=http://127.0.0.1:9000 npm run dev:h5
```

H5 生产默认使用同源 `/api`，由已有 Nginx 路由承接。`VITE_API_BASE_URL` 可覆盖 API origin（不含 `/api`），这是公开构建配置，不能填密钥。跨域 H5 需要服务端单独配置允许来源；本 Task 未放开后端 CORS。

微信小程序必须在构建前设置真实服务 HTTPS origin，并在微信平台配置合法 request 域名：

```bash
VITE_API_BASE_URL=https://你的实际服务域名 npm run build:mp-weixin
```

开发编译 `dev:mp-weixin` 可使用显式 HTTP 开发地址；真机须能访问该地址，不能使用开发电脑的 localhost。正式构建缺少 HTTPS 地址时显示服务暂不可用，不向相对路径或默认第三方地址发请求。本仓库不保存环境配置，不提供不存在的默认生产域名。

## 验证

必要检查：`npm ci`、`npm run type-check`、`npm run build:h5`、`npm run build:mp-weixin`。

`frontend/tests/guides.browser.cjs` 是 Playwright 浏览器回归脚本。前置条件：用测试服务器提供构建后的 H5，并将 `/api` 转发给当前空内容包的真实后端；环境中需有 Playwright 和 Chromium。运行：

```bash
H5_TEST_BASE_URL=http://127.0.0.1:你的测试端口 node frontend/tests/guides.browser.cjs
```

如 Playwright 安装在独立工具目录，可通过 `NODE_PATH` 指向该目录的 node_modules，不需要修改产品依赖。脚本先验证真实后端空列表和草稿 404，再在浏览器网络层注入合成数据覆盖有内容、分页、错误及竞态路径，测试样本不进入生产前端或后端包。截图写在 `/tmp`。实际结果和未验证范围见 [VALIDATION](../VALIDATION.md)。
