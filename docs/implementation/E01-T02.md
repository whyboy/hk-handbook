# E01-T02：工具页与工具说明框架

关联 Task #27。首页“查看全部工具”进入四张工具卡片：银行开户匹配、高才资格初筛、优才资格初筛、赴港清单生成。首页三类快捷入口保留；申请身份先选择高才／优才。

## 运行与路由

在 frontend 执行 `npm ci`、`npm run dev:h5`。微信执行 `npm run build:mp-weixin`，用开发者工具导入 dist/build/mp-weixin 并配置自己的 AppID。

- `/pages/tools/index`：工具列表。
- `/pages/tools/intro?scene=bank|talent|quality|checklist`：独立用途、未来输入与输出说明。`scene=identity` 保留首页人才路径选择。
- `/pages/tools/result?scene=bank|talent|quality|checklist`：结果空状态，明确未执行计算，并非一次测评结果。

H5 地址使用 `/#/pages/...`。参数仅按固定工具标识查找，未知及缺失值显示不可用说明。不会采集答案、发送业务请求、运行规则或保存记录。功能按钮禁用并显示“功能建设中”；“查看结果页面说明”仅打开空状态。

返回工具页／首页按目标查找页面栈；直达、刷新或目标不在栈中时重新打开目标页。四 Tab 仍由 T05 统一。

## 人工走查

1. 首页进入全部工具，依次打开四张卡片，确认高才和优才分开。
2. 查看用途及未来输入输出，确认建设中按钮不可执行；查看结果页面说明，确认无伪造结果。
3. 从说明和结果页分别返回工具页、首页；首页申请身份 → 高才／优才 → 返回首页。
4. 直接打开或刷新说明／结果地址，验证返回；移除或改错 scene，确认不可用状态。
5. 窄屏、桌面及微信开发者工具／真机核对布局、点击、返回与安全区。

实际验证见 VALIDATION.md。微信开发者工具、真机及产品人工验收待执行。
