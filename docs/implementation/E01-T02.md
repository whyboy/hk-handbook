# E01-T02：工具页与工具说明框架

关联 Task #27。工具栏目用于计算和比较类小工具，按产品确认顺序展示汇率换算、税后工资估算、Offer 收入对比、生活预算计算和租房入住预算五个筹备中入口。办理指引由首页六主题承接，不再将赴港清单、银行开户匹配、高才或优才初筛作为工具栏主内容。

## 运行与路由

在 frontend 执行 `npm ci`、`npm run dev:h5`。微信执行 `npm run build:mp-weixin`，用开发者工具导入 dist/build/mp-weixin 并配置自己的 AppID。

- `/pages/tools/index`：工具列表。
- `/pages/tools/intro?scene=exchange|net-salary|offer|living-budget|rental-budget`：独立用途和筹备中说明。
- `/pages/tools/result?scene=exchange|net-salary|offer|living-budget|rental-budget`：结果空状态，明确未执行计算。

H5 地址使用 `/#/pages/...`。参数仅按固定工具标识查找，未知及缺失值显示不可用说明。不会采集答案、发送业务请求、运行规则或保存记录。功能按钮禁用并显示“正在准备，敬请期待”。工具介绍页展示用途及两步规划，不提供表单或结果入口；旧结果链接仍保留空状态兼容。

返回工具页使用 switchTab，支持直接进入介绍页后的返回。四 Tab 由 T05 统一。

## 人工走查

1. 从底部 Tab 进入工具，核对五张单列卡片的名称、用途和顺序，并依次打开。
2. 查看用途及未来输入输出，确认建设中按钮不可执行；直接访问旧结果地址，确认无伪造结果。
3. 从说明和结果页返回工具页。
4. 直接打开或刷新说明／结果地址，验证返回；移除或改错 scene，确认不可用状态。
5. 窄屏、桌面及微信开发者工具／真机核对布局、点击、返回与安全区。

实际验证见 VALIDATION.md。微信开发者工具、真机及产品人工验收待执行。

## 工具栏目视觉

五项工具使用统一的单列卡片，每张卡片只展示图标、名称、一句用途说明及进入符号，整张可点击。工具数量较少，不增加分类、搜索、排行或推荐区。本次不设计表单、业务计算、输入采集或存储；具体使用方式、算法、税年及数据来源后续确认。

旧结果地址也沿用相同标题区、用途面板和留白布局；未知／缺失工具参数显示统一不可用状态。所有卡片统一标注“筹备中”，不暗示已确定上线日期。
