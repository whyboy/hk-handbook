# E01-T04：我的页面与记录列表框架

关联 Task #29。首页“我的收藏与记录”打开我的页面，包含我的收藏、办事清单、测评记录、反馈四个入口。前三项显示未接入业务的空页面，不声称已查询个人数据；反馈展示禁用的输入布局，不接收或提交答案。

## 运行和路由

在 frontend 执行 `npm ci`、`npm run dev:h5`。H5 使用 hash 路由：

- `/#/pages/profile/index`：我的页面。
- `/#/pages/profile/records?type=favorites`：收藏空页面；type 另支持 checklists、assessments。
- `/#/pages/profile/feedback`：反馈类型、问题说明和参考来源布局，全部禁用。
- `/#/pages/checklist/detail?demo=layout`：清单布局示例，包含出发前、办理中、完成后三阶段和禁用的步骤勾选。

清单列表中的“查看清单布局示例”用于评审框架，不是个人记录。没有 demo=layout 或携带 id 时，清单详情显示不可用，不把示例冒充真实清单。未知／缺失记录类型显示不可用页面。

所有子页可返回我的或首页，清单详情另可返回清单列表。直接进入和刷新没有历史栈时重新打开目标。页面不读写本地存储、不调用业务 API、不生成进度或提交成功反馈；未来本设备保存的说明采用将来时。四 Tab 在 T05 统一。

微信执行 `npm run build:mp-weixin`，用开发者工具导入 dist/build/mp-weixin 并配置自己的 AppID，设置上述编译页面与参数。

## 人工走查

1. 首页 → 我的 → 四入口，分别核对空状态和返回路径。
2. 清单列表 → 布局示例，核对三阶段、禁用勾选与建设中按钮；返回清单列表、我的、首页。
3. 反馈页输入区和提交按钮不可用，没有成功提示。
4. 直接打开并刷新所有页面；用未知或缺失 type、未知 demo、id 参数检查不可用状态及返回。
5. 窄屏、桌面和微信真机核对换行、控件、返回及安全区。

验证记录见 [VALIDATION.md](../VALIDATION.md)。按本次用户明确授权，CI 通过后合并 PR 并关闭 Task；微信真机和产品人工验收待办仍如实保留。
