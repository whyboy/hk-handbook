# E01-T03：攻略页与详情框架

关联 Task #28。首页攻略卡片打开对应示例详情，“查看全部攻略示例”进入攻略列表。四分类为银行卡、手机卡、人才身份、生活落地，另有“全部”；分类仅切换本地展示样例，不接内容接口或搜索。

## 运行与评审入口

在 frontend 执行 `npm ci`、`npm run dev:h5`，打开终端地址。H5 使用 hash 路由：

- `/#/pages/guides/index`：列表，四篇静态样例。
- `/#/pages/guides/detail?id=bank-preparation`：标题、摘要、正文及来源区域。
- 其他示例 ID：`mobile-preparation`、`talent-paths`、`first-visit`。
- 列表追加 `?demo=loading`、`?demo=empty`、`?demo=error` 查看加载、空列表及失败展示。
- 详情追加 `&demo=loading` 或 `&demo=error` 查看加载／失败；`&demo=empty`、缺失或未知 id 显示不存在状态。

`demo` 仅供框架评审；没有真实请求、重试或查询。状态说明明确标注为示例，按钮恢复静态样例。未知 demo 值回到默认状态。所有内容仅用固定 ID 查找，不插入 URL 中的正文或 HTML。

页面持续标注“框架示例 · 尚未核验，不作为办事依据”；无虚构来源链接、核验日期或真实政策事实。不存在状态不展示旧正文。无收藏、分享、反馈、存储和业务请求。

返回列表优先恢复已有列表（保留分类），没有列表页面栈则重新打开列表；返回首页定位首页，直接进入和刷新同样可返回。沿用统一导航方法，四 Tab 在 T05 交付。

微信执行 `npm run build:mp-weixin`，用开发者工具导入 dist/build/mp-weixin 并配置自己的 AppID。可在自定义编译模式设置页面及上述查询参数。

## 人工验收路径

1. 首页三张示例卡片分别进入详情，核对标题及示例标识。
2. 全部攻略 → 四分类 → 详情 → 返回列表，核对分类保留；返回首页。
3. 直接打开、刷新四篇详情，返回列表或首页。
4. 按上述参数逐个查看列表／详情状态；异常 ID 不展示正文。
5. 320px 窄屏、桌面、微信开发者工具与真机核对换行、卡片、按钮及安全区。
