# E02-T06 首页六主题导航

对应 #61。首页以两行三列显示港卡办理、高才／优才申请、电话卡办理、交通指南、景点推荐、税务指南，替换原三个任务入口，移除“查看全部工具”。保留搜索、推荐攻略、四 Tab 及个人记录入口。

`features/topics/content.ts` 管理主题名称和顺序，导航使用 `openTopic`；`pages/topics/` 六个独立 Vue 页面复用 TopicPlaceholder，仅显示标题、内容整理中、返回首页。不加载主题业务数据，不实现评论或投票。图标沿用 CSS 绘制，无新增图片生成或依赖。

工具 Tab 的旧框架和旧路由暂保留，具体计算类工具后续开发；首页不再进入旧工具说明。六主题不改变攻略的四分类模型。后续公开票数规范见 [PRD](../PRD.md)，本次没有投票 API、数据库表或假计数。

## 运行与检查

按 README 启动前端。首页逐项点击六入口；独立地址 `/#/pages/topics/bank`（其余 talent / phone / transport / attractions / tax）支持直达、刷新及返回首页。微信开发者工具按 pages.json 的对应路径打开。

构建：`cd frontend && npm ci && npm run type-check && npm run build:h5 && npm run build:mp-weixin`。

浏览器回归：以静态服务器提供 `frontend/dist/build/h5`，执行 `NODE_PATH=/外部工具/node_modules H5_TEST_BASE_URL=http://127.0.0.1:端口 node frontend/tests/topics.browser.cjs`。脚本拦截攻略 API 为空列表，不模拟真实发布内容；检查六入口、两行三列、四种宽度、直达刷新返回、搜索和 Tab。

历史 E01 首页设计以当时交付为准，当前首页以本文和 PRD 为准。原 E03～E08 规划取消，详见 ROADMAP；未提交草稿保留在原工作区，不纳入本次变更。
