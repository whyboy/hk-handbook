# 第一次乘港铁，怎样查路线和尾班车？

- ID：mtr-route；版本：1；状态：待人工核验，未发布。
- 分类：交通；人群：游客、人才用户、家庭；关键词：港铁、地铁、路线、换乘、末班车。
- 摘要：先确认起终点，再在官方工具核对路线与首尾班信息。
- 选题理由：解决首次出行的具体查询问题，适用于三类人群；不依赖无法核实的个案开户经验，也不写固定票价承诺。

- 编辑与资料查阅：2026-10-17；发布日期、人工事实核验日期：无；发布前核验，之后建议 90 天复核。

## 适用条件

计划乘港铁且能够确定起终点。本文提供查询方法，不判断跨境资格或票种优惠资格。

## 准备事项

起点与目的地名称，以及可访问官方工具的联网设备。申请材料不适用：这是一篇查询教程，不是办理业务。

## 操作步骤

1. 打开 MTR Mobile 的行程规划，从首页选择 “Where to?”。（S1）
2. 选择起点和终点，查看建议路线及行程信息。（S1）
3. 核对换乘和首尾班信息，尤其是晚间返程；官方服务时间页提供查询入口。（S2）
4. 出发前重新查看官方服务资讯。（编辑建议，不是服务保证。）

## 费用与耗时

不列固定票价或车程；具体行程在官方工具查询。估计行程时间不是抵达承诺。

## 注意事项

应用界面可能变化，查询失败可从下方官方说明入口确认。本文未核验特定路线，未进行手机实操。
个人经验：无。待核验：人工确认来源与当前界面、完成一次实际路线查询，不能声称本文已完成这些步骤。
