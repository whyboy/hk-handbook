## 逐项检查

- [ ] 一篇回答一个明确问题；分类、人群、摘要和关键词一致。
- [ ] 标签不作为法定资格认定，个人经验包含具体时间与情境。
- [ ] 资格、证件、材料、费用、时效均有逐项来源和适用条件。
- [ ] 人工实际打开并检查原始来源，记录核验人及日期，未将 AI 查阅当作人工核验。
- [ ] 来源的机构、产品、地区、对象和生效范围相符，没有未处理冲突。
- [ ] 官方事实、个人经验、编辑建议、待核验信息分开表达。
- [ ] 未知与不适用不同：未知不能写成“无需”“免费”“一定成功”。
- [ ] 已移除无依据承诺、个人敏感信息及无法核实的关键结论。
- [ ] 发布日期、编辑日期、逐条事实核验日期分别记录，复核期限明确。
- [ ] 三种主题的补充字段已填写或注明不适用原因。
- [ ] 页面能看到适用条件、来源及核验状态，长文阅读顺序清楚。
- [ ] 纠错入口、下架后的分享链接与收藏状态有明确说明。
