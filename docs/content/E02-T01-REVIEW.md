## 发布边界推演

以下是契约逐项审查，不是运行时测试通过；#31 必须实现针对这些情况的自动测试。

| 输入情境 | 必须得到的结果 |
| --- | --- |
| 模板原样，或仅将 draft 改为 published | 无法公开：unknown 正文／日期、空事实／来源、无人工签字 |
| AI consultedOn 有值，verification=null | 无法公开，查阅不替代核验 |
| 任一事实缺 sourceIds 或引用不存在 ID | 结构／引用不合格，拒绝数据集生效 |
| 人工证据是旧 revision 或仍有 changes_requested | 无法公开，不能复用旧审核 |
| URL 返回 200 但内容无依据、链接失效／未知 | 无法公开，HTTP 成功不代表事实有效 |
| 正好到 reviewDueOn／until 当天，或尚未到 from | 不公开正文；日期按香港日期、截止日不含当天 |
| costsAndTime 未知写成 0 或空字符串 | 类型／状态不合格，不允许伪装免费 |
| unknown 与 not_applicable | 前者阻塞；后者必须有理由并经人工审核，步骤／适用条件不可不适用 |
| 重复 JSON 键、未知字段、重复 ID、非法日期 | 拒绝生效，不能静默采用最后一值 |
| 全部门槛通过且人工实际授权 published | 可公开投影，不泄露内部签字、笔记、私人数据 |
| 草稿 ID 直达、下架 ID 直达、搜索无结果 | 分别 404、无正文 410、正常空列表；草稿不泄露总数 |
| 引用目标不存在或版本未开放 | 文章可保留相关说明，不能展示可执行按钮 |
